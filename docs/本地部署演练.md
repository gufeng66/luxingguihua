# 本地部署演练

单进程，不用容器，不用反向代理。下面的启动方式不加 `--reload`。

## 启动

在仓库根目录：

```bash
python -m planner.preflight
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000/`。`GET /api/health` 只表示进程还在。`GET /api/ready` 分开看配置和 12306 的 HTTP 是否可达；MCP 连不上时应用仍就绪，并标为降级。

## 停止

在启动它的终端按 Ctrl+C。进程退出时会取消还在进行的规划。

## 配置

密钥放在仓库根目录的 `.env`，不要写进页面、日志或评测产物。缺 `OPENAI_API_KEY` 或高德密钥时，`python -m planner.preflight` 只打印缺哪一项，不打印值。

## 备份

回退代码之前先停掉本机服务，再复制整个 `workspace/results/`。服务还在写库时，用 `sqlite3 plans.db ".backup plans-backup.db"`，不要在写入过程中直接拷贝正在使用的库文件。

恢复就是把这份复本放回去。旧快照没有质量字段时仍能打开。旧的 `plans` 行补列之后，列表里显示「未记录核实状态」，不会被当成已核实。
