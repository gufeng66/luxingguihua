# ADR-1：summary 不是 agent

## 状态

接受

## 背景

最终方案是固定六章节的 Markdown。若再包一层带工具的 agent，它会在成文阶段继续查票、改文件，既多花钱，也让「禁止编造」无法在出口处一次说清。

## 决策

`stream_summary` 是编排层的一次无工具 LLM 调用。票务态和地图态先写成约束段落再交给模型。成文之后、落盘之前跑闸门：六个章节必须在；票务不是 `ok` / `reused` 时，「车票建议」里不能有车次号。失败把失败原因写回提示词重试一次。仍失败则用 `degraded_plan` 替换正文再落盘。

## 后果

成文不能临场补查。缺数据时章节里写明暂缺，而不是再调 MCP。闸门用 `evals/test_gate.py` 证明：编造的车次号不会进入 `final.content`。
